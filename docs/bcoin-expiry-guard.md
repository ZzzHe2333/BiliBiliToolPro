# B币券临期自动充电

本 fork 的青龙订阅中，`Zzz-Bili 免费B币券充电任务` 可以每天运行，但不会每天消费 B 币券。

## 判定规则

1. 只有年度大会员参与。
2. `Zzz-Bili 领取大会员福利任务` 成功领取“年度大会员每月赠送的B币券”时，记录实际领取时间。
3. 预计到期时间固定按：`领取成功时间 + 30 天`。
4. 免费 B 币券充电任务每天检查一次：
   - 没有可信领取记录：不自动充电；
   - 距预计到期超过 48 小时：不自动充电；
   - 已超过预计到期时间：不使用陈旧记录自动充电；
   - 进入到期前 48 小时且 B 币券余额不少于 2：才执行自动充电；
   - 本期已自动充电：后续检查直接跳过。
5. 充电目标仍按账号级配置 > 全局配置 > fallback UID 的顺序决定。

## 状态文件

青龙环境下按 B 站 UID 分文件保存到：

```text
/ql/data/config/zzz-bilibili-tool/bcoin-coupon-<B站UID>.json
```

如果设置了 `QL_DATA_DIR`，则使用：

```text
$QL_DATA_DIR/config/zzz-bilibili-tool/bcoin-coupon-<B站UID>.json
```

状态文件位于订阅仓库目录之外，因此重新运行订阅、重新拉取 Git 仓库不会删除它。

## 旧券说明

升级到本版本前已经领取、但程序没有记录领取时间的 B 币券，不会猜测到期日期后自动消费。这样做是为了避免误把新券或其他余额提前充掉。下一次通过本 fork 成功领取 B 币券后会自动建立可信状态。
